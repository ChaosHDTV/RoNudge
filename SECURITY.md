# Security

## Downloads

The only official download is the Releases page of this repository. Each release lists the SHA-256 of
`RoNudge.exe`; compare it before running a copy you got from anywhere else.

## What the program does on your PC

RoNudge sends keyboard and mouse input to Roblox windows, changes their visibility, opacity and position,
mutes their audio session, and, for the FPS limiter, briefly suspends and resumes Roblox's threads. Some
antivirus products flag that behaviour in any program.

It stores settings under `HKCU\Software\RoNudge`. Network access is limited to the update check against
this repository and to the Discord webhook URL you enter yourself.

## Reporting a problem

Please report security problems privately through this repository's **Security** tab ("Report a
vulnerability") instead of a public issue.
